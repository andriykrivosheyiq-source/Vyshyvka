# Нова пошта і контроль оплати — що зробити, щоб працювало (21.10.2026)

Робиться один раз. Далі новий ФОП — три кроки з розділу «Новий ФОП».

## Що змінилось у коді

- `loomiq-np` (накладні): отримувач заводиться в Новій пошті перед
  накладною; місто, контакт і дата передаються так, як вимагає НП.
- `loomiq-money` (гроші): Нова пошта опитується по кожному відправнику його
  ключем `NP_KEY_<код>`. Контроль оплати лягає на рахунок НП цього ФОПа.
- Адмінка: біля відправника видно стан ключа; у картці рахунку НП можна
  обрати відправника.

Без перерозгортання двох воркерів зміни не діють.

## 1. Перерозгорнути `loomiq-np` (2 хвилини)

1. dash.cloudflare.com → Workers & Pages → **loomiq-np** → **Edit code**.
2. Ліворуч Ctrl+A, видалити. Вставити вміст `worker/novaposhta-proxy.js`
   (GitHub → гілка `main` → файл → Raw → Ctrl+A, Ctrl+C).
3. **Deploy**.

Секрети не чіпаються. Там уже має бути `NP_KEY_yukalchukOleksandr`
(назва = код відправника з Налаштування → Відправка).

## 2. Перерозгорнути `loomiq-money` (3 хвилини)

1. Workers & Pages → **loomiq-money** → **Edit code** → замінити вміст на
   `worker/money.js` → **Deploy**.
2. Settings → Variables and Secrets → **Add** → тип **Secret**:
   - назва `NP_KEY_yukalchukOleksandr`
   - значення — той самий ключ API Нової пошти, що в `loomiq-np`.
3. Старий `NP_API_KEY` можна лишити, він не заважає.

## 3. Перевірити (5 хвилин)

1. Адмінка → Налаштування → Відправка: біля «ФОП Юкальчук» за пів години
   має зʼявитись **«✅ ключ працює · перевірено …»**. Якщо «❌ немає
   секрета NP_KEY_…» — назва секрету в `loomiq-money` не збігається з
   кодом; якщо «❌ ключ не приймається» — ключ протермінований, створіть
   новий у кабінеті НП і оновіть в обох воркерах.
2. Картка замовлення → Доставка → «Створити ТТН». Отримувач — «Прізвище
   Імʼя» кирилицею, місто й відділення — зі списку.
3. Фінанси → Рахунки: на рахунку «Нова пошта» має стояти «перевірено …».

## Як рухаються гроші за накладеним платежем

1. ТТН створюється з контролем оплати = залишок за замовленням
   (`LQMoney.codFor`). Більше чи менше — Звірка покаже червоним.
2. Посилку забрали → воркер грошей бачить це за пів години → рух
   «Контроль оплати · ТТН …» на рахунку НП цього ФОПа.
3. Адмінка привʼязує рух до замовлення за номером ТТН сама. Замовлення
   стає «сплачено повністю».
4. Якщо посилку забрали, а руху немає понад 2 дні — Звірка: «забрали,
   грошей немає». Відмова чи повернення — Звірка: «контролю не буде,
   перевірте товар». Гроші за ТТН, якої немає в CRM, — Звірка: «накладна
   повз CRM».

Переказ з NovaPay на рахунок ФОПа йде пулами і зі Звіркою не звіряється
(домовлено 21.10).
