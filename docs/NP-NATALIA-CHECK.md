# Нова пошта: перевірка переходу з ФОП Олександра на ФОП Наталії

Для людини, яка відповідає за відправки. Мета — переконатися, що **нові
накладні йдуть лише від Наталії**, а гроші за накладеним платежем —
на її рахунок. Нічого не видаляти й не міняти, лише подивитися й
записати відповіді. Питання — Андрію.

## Перевірити (≈10 хв)

1. **Кабінет НП Олександра** → «Мої відправлення», від дня переходу.
   Нових накладних там бути не має.
   → Є нові? Випишіть їхні номери.
2. **Кабінет НП Наталії** — нові накладні з дня переходу є там.
3. **Cloudflare → `loomiq-np` → Settings → Variables and Secrets**:
   - є секрет `NP_KEY_<код Наталії>`? (код — у CRM: Налаштування →
     Відправка, під її назвою);
   - є `NP_API_KEY`? Чий це ключ — Олександра, Наталії, інший?
   **Нічого не видаляти.**
4. **Cloudflare → `loomiq-money`** — те саме: є `NP_KEY_<код Наталії>`?
5. **CRM → Налаштування → Відправка**:
   - Наталія — «за замовчуванням»?
   - біля Наталії — «✅ ключ працює»?
6. **CRM → Фінанси → рахунки**: є рахунок «Нова пошта», у якому обраний
   відправник **Наталія** і ФОП — її?
7. **3–5 свіжих карток**: у блоці ТТН рядок «Відправник» — Наталія?
8. **Кабінет НП Наталії → договір**: дозволений «Контроль оплати»
   (накладений платіж)?

## Відповідь Андрію (скопіювати й заповнити)
```
1. Нові накладні в кабінеті Олександра після переходу: немає / є: …
2. Нові накладні в кабінеті Наталії: так / ні
3. loomiq-np: NP_KEY_<Наталія> — є / немає; NP_API_KEY — є (чий: …) / немає
4. loomiq-money: NP_KEY_<Наталія> — є / немає
5. Наталія за замовчуванням — так / ні; «ключ працює» — так / ні
6. Рахунок «Нова пошта» Наталії у Фінансах — є / немає
7. Свіжі картки — відправник Наталія: так / ні (номери, де ні: …)
8. Контроль оплати в договорі Наталії — так / ні
```

## Чому це важливо (з коду CRM)
- Картка, де у формі доставки **колись вручну обрали Олександра**, і далі
  створює й перестворює ТТН від нього — «за замовчуванням» на неї не діє.
- Якщо у воркері немає ключа Наталії, а є старий `NP_API_KEY`, накладна
  **мовчки** створюється в кабінеті власника `NP_API_KEY`, хоча CRM показує
  Наталію.
- Без рахунку «Нова пошта» Наталії у Фінансах гроші за її посилками лягають
  на рахунок НП Олександра.

Ці три місця закриває доробка «Олександр — не для нових» (план, блок Г).
