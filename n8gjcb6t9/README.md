# Запрошення на побачення

Короткий сайт із п'яти сторінок, тексти — російською. Кожен крок — окрема сторінка,
переходи звичайними внутрішніми посиланнями.

```
index.html  →  yes.html  →  when.html  →  what.html  →  done.html
запрошення     згода        час           що робимо     підсумок + .ics
```

## Без домена

У розмітці немає жодного абсолютного посилання — тільки імена файлів поруч
(`href="yes.html"`, `href="what.html?d=…&t=…"`). Тому папку можна перейменувати,
покласти в будь-яке місце сайту, віддати з іншого домена чи сабдомена або просто
відкрити `index.html` з диска — переходи однаково працюють.

## Щоб не знайшли випадково

Назва папки — випадковий код, тож адресу не вгадати. На кожній сторінці стоїть
`<meta name="robots" content="noindex">`, і з основного сайту сюди немає жодного
посилання, тож у пошук воно не потрапляє. Перейменувати папку можна будь-коли —
нічого правити не треба, посилання всередині відносні.

Так само немає зовнішніх запитів: шрифти системні, іконка — inline SVG,
файл календаря `.ics` збирається в браузері.

## Що зафіксовано

- дата — завжди сьогоднішня, змінити не можна;
- час — лише з 21:00 до 23:55 з кроком 5 хвилин;
- кнопка «Нет» тікає по всьому екрану, міняє 20 фраз, прощається й вилітає
  з екрана назовсім — далі лишається тільки «Да».

## Події та адмінка

`track.js` пише кроки (відкрила, тікала від «Нет», погодилась, обрала час,
обрала план, дійшла до кінця) у Firestore через REST — без SDK. Гілка подій
живе за випадковим токеном, правило для неї — у `firestore.rules`
(`match /dateInvite/{token}/events/{event}`). Дивитися — окрема сторінка
`/pzfe78egr/`. Якщо база недоступна чи правила не опубліковані, сайт просто
працює далі: подія мовчки губиться, гість нічого не помічає.

## Фото

Поклади у цю папку `photo.jpg` — воно з'явиться на першій сторінці замість
ведмедика. Файлу немає — показується емодзі, нічого не ламається.

## Дані між кроками

Дата, час і план їдуть у query-рядку посилання (`done.html?d=2026-07-29&t=18:30&p=sushi`),
а `sessionStorage` дублює їх, щоб сторінка пережила перезавантаження. Якщо відкрити
`what.html` чи `done.html` без деталей — редірект на початок.

## Що правити

- тексти й емодзі — прямо в HTML сторінок;
- ім'я в запрошенні та підпис у кінці — `index.html` і `done.html`;
- фрази кнопки «Нет» — масив `excuses` в `index.html`;
- список варіантів побачення — `PLANS` у `app.js`;
- адреса гілки подій — `TOKEN` у `track.js` і в адмінці;
- кольори й розміри — змінні `:root` на початку `style.css`.
